# Cassandra v0.1.0

The first public release of Cassandra's shared vulnerability analysis engine, headless CLI, and risk-oriented dependency explorer.

## Scan without a server

- Analyse a local checkout without cloning it or executing its install, build or test scripts.
- Produce JSON, Markdown, CycloneDX 1.6, SPDX 2.3 and SARIF 2.1.0 reports.
- Distinguish policy success (`0`), blocking findings (`1`) and incomplete/failed analysis (`2`).
- Preserve diagnostic artifacts before returning a policy failure.
- Download Linux/macOS binaries for amd64/arm64 from this release and verify them with `checksums.txt`.

## Risk-oriented graph exploration

- Find vulnerable components through a ranked, filterable list instead of searching a zoomed-out graph.
- Start with project/manifest summaries and progressively explore dependencies.
- Separate vulnerable components from their dependency context and inspect a selected component in a persistent detail panel.
- Navigate with a bottom-right minimap, explicit viewport/zoom controls and responsive layouts.

## Maintainable boundaries and error handling

- Shared web/CLI analysis pipeline; small provider, cache, report-store and execution contracts.
- Separate remediation state management from side-effecting step commands. Human approval remains required before push/PR/deploy.
- Preserve unresolved dependency diagnostics and reject malformed/incomplete vulnerability-service responses.
- Protect report writes against directory-link redirection and preserve caller cancellation separately from provider timeouts.

## GitHub Action

The lightweight adapter is maintained separately at [jinho-yoo-jack/cassandra-action](https://github.com/jinho-yoo-jack/cassandra-action). It uses an exact CLI release and does not duplicate the engine. Marketplace listing status and workflow usage are documented in that repository; a CLI release alone is not Marketplace registration.

## Scope and limitations

This is a pre-1.0 release. The Kubernetes-style service API remains `v1alpha1`. Scanning requires access to public vulnerability services and, for Go graph expansion, a module proxy. Detection is limited by supported manifests and available advisory data; a clean result is not proof that software is secure. Container OS package scanning, authenticated multi-tenancy, and PR baseline/delta policy are not included.
